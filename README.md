# HappyMeals
Приложение на C++ c фреймворком Qt и Docker для подбора блюд на основе предпочтений пользователя.

## Описание
Программа помогает пользователю определиться, что приготовить, учитывая:
- Нежелательные ингредиенты
- Предпочитаемую кухню (итальянская, японская, русская, китайская, мексиканская)
- Максимальное время приготовления

## Структура проекта
```
happy_meals/
├── src/              # Исходные файлы (.cpp)
├── include/          # Заголовочные файлы (.h)
├── data/             # База данных SQLite
├── HappyMeals.pro    # Файл проекта Qt
├── Dockerfile        # Конфигурация Docker
└── README.md
```

## Функции
- Регистрация и авторизация пользователей
- Подбор блюд с учетом нежелательных ингредиентов
- Фильтрация по типу кухни
- Фильтрация по времени приготовления
- История запросов и статистика

## Технологии
- Язык: C++11
- Компилятор: g++
- Фреймворк: Qt 5 (QtNetwork, QtSql)
- База данных: SQLite
- Контейнеризация: Docker

## Сборка и запуск

### С помощью Docker
```bash
docker build -t happymeals .
docker run -p 33333:33333 -v $(pwd)/data:/data happymeals
```

### Локальная сборка
```bash
qmake HappyMeals.pro
make
./HappyMeals
```

## Протокол взаимодействия

Сервер работает на порту 33333. Формат команд: `команда:параметры`

### Команды

#### Регистрация
```
reg:login,password,email
```
Ответ: `OK:Регистрация успешна` или `ERROR:Логин уже занят`

#### Авторизация
```
auth:login,password
```
Ответ: `OK:Авторизация успешна` или `ERROR:Неверный логин или пароль`

#### Подбор блюда (NEW FORMAT)
```
get_dish:ingredients;cuisines;maxTime
```

**Формат с множественными фильтрами:**
- `ingredients` - список нежелательных ингредиентов через запятую (например, "помидор,яйцо")
- `cuisines` - список типов кухни через запятую (japanese/японская, italian/итальянская, russian/русская, chinese/китайская, mexican/мексиканская)
- `maxTime` - максимальное время приготовления в минутах

**Все параметры опциональны. Используйте пустые значения для пропуска.**

Примеры:
```
get_dish:помидор,яйцо;italian,japanese;20    # Итальянская или японская кухня без помидоров и яиц, до 20 минут
get_dish:;;30                                # Любое блюдо до 30 минут
get_dish:яйцо,курица                         # Любое блюдо без яиц и курицы
get_dish:;italian,russian                    # Только итальянская или русская кухня
get_dish:помидор;italian;15                  # Итальянская кухня без помидоров, до 15 минут
get_dish:                                    # Все доступные блюда
```

Ответ: `OK:Омлет (10 мин), Цезарь (15 мин)` или `ERROR:Нет блюд удовлетворяющих вашим предпочтениям`

#### Статистика
```
get_stat
```
Ответ: `OK:Пользователь: username, Запросов подбора: 5` или `ERROR:Вы не авторизованы`

## Примеры использования

```bash
# Подключение к серверу
telnet localhost 33333

# Регистрация
reg:john,pass123,john@example.com

# Авторизация
auth:john,pass123

# Поиск быстрых блюд итальянской или японской кухни
get_dish:;italian,japanese;20

# Поиск блюд без курицы и помидоров
get_dish:курица,помидор

# Поиск русских блюд без яиц, до 25 минут
get_dish:яйцо;russian;25

# Просмотр статистики
get_stat
```

## База данных блюд

Блюда хранятся в отдельной базе данных `/data/dishes.sqlite` со следующей структурой:

### Таблицы:
- **dishes** - информация о блюдах (название, кухня, время приготовления)
- **ingredients** - список всех ингредиентов
- **dish_ingredients** - связь многие-ко-многим между блюдами и ингредиентами

- Лосось на гриле (японская, 15 мин)
